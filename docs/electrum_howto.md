# Electrum How-To

This document shows how to import a WIF into Electrum (client) and verify the address and transactions.

1. Open Electrum (GUI) -> File -> New/Restore -> Create a new wallet name.
2. Choose 'Import Bitcoin addresses or private keys'.
3. Paste the WIF (from keys/private_key.wif) and continue.
4. Electrum will show the address and allow you to broadcast signed hex.

CLI: electrum commands differ by version; check your Electrum docs. Never paste WIF into an online service.
